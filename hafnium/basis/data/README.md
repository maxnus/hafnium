# Bundled basis set data

These files are the JSON responses of the Basis Set Exchange REST API for
the elements hydrogen through argon, bundled so that tests and examples
run offline. Everything else is fetched on demand and cached (see
`hafnium.basis.library`).

Source: https://www.basissetexchange.org (MolSSI and EMSL), BSD-3-Clause.
If you use these basis sets in published work, cite Pritchard et al.,
J. Chem. Inf. Model. 59, 4814 (2019), and the original basis set
references listed under each element's `references` key.
